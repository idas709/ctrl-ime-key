# ctrl-ime-key

USキーボードの **左右 Ctrl キーの空打ち（単体タップ）** で、IMEのオン／オフ（日本語／英数入力）を直感的に切り替えるWindows常駐ユーティリティです。Rustによるネイティブ実装で、超軽量（バイナリ約145KB）かつ低遅延で動作します。

---

## 主な機能

- **右 Ctrl の空打ち**：**IME ON**（日本語入力 / かな）
- **左 Ctrl の空打ち**：**IME OFF**（英語入力 / 英数）
- **通常のショートカットキーを妨げない**：
  - `Ctrl + C`、`Ctrl + V`、`Ctrl + A` などの組み合わせ入力時はIME切り替えを行わず、通常のCtrlキーとして動作します。
- **長押しタイムアウト防止**：
  - Ctrlキーを長押し（デフォルト1000ms以上）したまま離した場合は空打ちとみなさず、誤動作を防ぎます。
- **タスクトレイ常駐**：
  - タスクトレイアイコンから「有効/一時停止」「IME切り替えモード」「終了」を簡単に操作できます。
- **超軽量・スタンドアロン**：
  - 外部ランタイム不要、メモリ使用量わずか数MB、CPU負荷実質ゼロ。

---

## 動作要件

- OS: **Windows 10 / Windows 11** (x64 / ARM64)
- キーボード: US配列キーボード（またはCopilotキーボード等、英数・かなキーのないキーボード全般）

## 使い方

### インストーラーを使う

Releasesから `ctrl-ime-key-<version>-setup-x64.exe` をダウンロードして実行します。
セットアップ時に、次のインストール方法を選択できます。

- **現在のユーザーのみ**：管理者権限なしでユーザー領域へインストール
- **すべてのユーザー**：管理者権限でProgram Filesへインストール

スタートアップへの登録は、セットアップ中の「追加オプション」で変更できます。

### 1. ビルド
```powershell
cargo build --release
```
`target\release\ctrl-ime-key.exe` に実行ファイルが生成されます。

### インストーラーのビルド

[Inno Setup 6](https://jrsoftware.org/isinfo.php) をインストールしたうえで、PowerShellから次を実行します。

```powershell
.\build-installer.ps1
```

`dist\ctrl-ime-key-<version>-setup-x64.exe` が生成されます。バージョン番号は`Cargo.toml`から自動取得されます。
同時に、インストール不要の `dist\ctrl-ime-key-<version>-standalone-x64.exe` も生成されます。

### 2. 起動
`ctrl-ime-key.exe` を実行すると、バックグラウンドで起動し、タスクトレイ（画面右下の通知領域）に常駐します。

### 3. タスクトレイ操作
タスクトレイのアイコンを右クリックするとメニューが開きます。

- **Enabled (有効) / Disabled (一時停止中)**：一時的にキーフックを停止できます。
- **Mode 選択**：
  - `IMM Message (alt-ime-ahk互換, 推奨)` [標準]：
    - WindowsのIMM32 APIメッセージ（`WM_IME_CONTROL`）を直接送信し、状態を確認して切り替えます。
    - 変換キーを送らないため、**「再変換」などの誤動作が絶対に発生しません**。
    - すでにONの状態で右Ctrlを押しても、すでにOFFの状態で左Ctrlを押しても何も起きないため、安全に連打できます。
  - `VK_IME_ON / OFF (Windows 10/11)`：Windows標準のIME ON/OFF仮想キーコード
  - `変換 / 無変換 (Henkan / Muhenkan)`：JIS配列の変換/無変換キー互換
  - `Hybrid (両方送信)`：仮想キーコードの互換モード
- **Exit (終了)**：常駐を解除して終了します。

### 4. コマンドラインオプション

```text
Usage: ctrl-ime-key.exe [OPTIONS]

Options:
  --console               デバッグログ表示用コンソールを割り当てて起動
  --mode <MODE>           起動時のIME切り替えモード (ime | convert | hybrid)
  --timeout <MS>          空打ち判定の最大時間ミリ秒 (デフォルト: 1000)
  -h, --help              ヘルプメッセージを表示
```

## Windows起動時に自動実行する（スタートアップ登録）

PC起動時に自動で常駐させたい場合は、以下の手順でショートカットをスタートアップフォルダに配置してください。

1. `Win + R` キーを押し、`shell:startup` と入力して Enter を押します（スタートアップフォルダが開きます）。
2. ビルドした `ctrl-ime-key.exe` のショートカットをそのフォルダ内に作成します。

---

## 注意事項 (管理者権限のアプリケーションについて)

Windowsのセキュリティ仕様（UIPI: User Interface Privilege Isolation）により、標準ユーザー権限で起動している常駐ツールは、**「管理者として実行」されているアプリケーション（管理者権限のターミナルやタスクマネージャー等）** のウィンドウ上ではキーフックがインターセプトできない場合があります。

管理者権限のウィンドウ上でも常に動作させたい場合は、`ctrl-ime-key.exe` も「管理者として実行」するか、タスクスケジューラで「最上位の特権で実行」としてスタートアップ登録することをおすすめします。
